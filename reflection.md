## Reflection on Group Work

### What worked well

- **Clear task allocation:**  
  Assigning specific responsibilities at the start of the project reduced confusion and prevented duplication of work.

- **Regular communication:**  
  The team used messaging tools to clarify doubts, share progress, and resolve technical questions quickly.

- **Use of GitHub for version control:**  
  GitHub enabled structured collaboration, version tracking, and organised storage of files such as cloud.md, security.md, ethics.md, and reflection.md.

- **Peer review of sections:**  
  Each member reviewed the other’s work (e.g., cloud costing, security controls, and ethics), which improved clarity and consistency.

---

### Issues encountered

- **Initial disagreement on network design:**  
  There were early differences in opinion regarding IP addressing and subnet structure, which delayed finalisation of the network diagram.

- **GitHub merge conflicts:**  
  Minor technical issues occurred when both students edited documentation simultaneously, requiring manual conflict resolution.

- **Time management challenges:**  
  Cloud pricing and risk assessment took longer than expected, leading to increased workload closer to the submission deadline.

---

### Recommended techniques for future group projects

| Technique | Problem it solves / How it helps |
|---|---|
| **Weekly task checklist** | Prevents last-minute rush and ensures steady progress across the term |
| **Written task allocation document** | Clarifies responsibilities and improves accountability |
| **More frequent, smaller Git commits** | Provides clearer evidence of contribution and reduces merge conflicts |
| **Regular scheduled meetings** | Improves coordination and allows early detection of problems |
| **Shared planning document ** | Centralises decisions, deadlines, and progress tracking |

Implementing these techniques in future projects would improve coordination, reduce stress, and enhance overall teamwork effectiveness.

## Conclusion

Overall, the group demonstrated effective collaboration, technical competence, and commitment to producing high-quality work. Despite challenges in network design, GitHub collaboration, and time management, both members made substantial contributions, and the final project reflects strong teamwork, structured planning, and continuous improvement throughout the term.
